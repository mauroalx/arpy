# Arpy (ARP ran in Python)

## What is Arpy?

**Arpy** is a simple yet powerful tool designed to locate IP addresses on a local network.
This software was created to address the challenge of finding DWDM management IPs (Huawei), especially when access to the Panel/SCC is unavailable, as well as for digital radios like SIAE, Comba, Ceragon, and other devices where the network analyst has lost track of the assigned IPs.

Arpy can locate a host within a /16 network in just a few seconds — or a few minutes if you're unlucky.

## How to use?

![image](https://github.com/user-attachments/assets/36c41faa-8175-4cec-80f0-518ab511b0de)

To start using Arpy, enter the target subnet in the Subnet field.
Before scanning, ensure your Windows network interface is configured within the same subnet. Alternatively, you can set the interface directly through the Config menu (requires running the application as administrator).

![image](https://github.com/user-attachments/assets/1412ae2e-4f90-406e-8e82-78d5e88b8813)


## Requirements

Npcap (https://npcap.com/dist/npcap-1.79.exe) – Please download it from the official repository.
Note: Windows includes WinPcap by default, so installing Npcap may not be necessary.
